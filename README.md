A tiny deterministic Node program for the [make.fun bounty "How Many Tabs Do You Have Open?"](https://make.fun/bounty/u-danu-how-many-tabs-do-you-have-open-d86e783d).

It writes one number — digits only, the honest count of open browser tabs — to `/output/entry.txt`. No network, no external dependencies.

Run it:

```sh
node main.ts
```
